# Poppy Keys

A colorful browser typing game for kids — pop bubbles by pressing the right keys!

## How to Play

1. Open `poppy-keys.html` in any modern browser — no installation needed.
2. Press **SPACE** to start.
3. Colorful bubbles float up, each showing a letter.
4. Press the matching key on your keyboard to pop the bubble before it escapes!
5. You have **3 lives**. Every 10 pops advances you to the next level.

## Features

- Single-file game — just one HTML file, no dependencies
- 8 levels with increasing speed and spawn rate
- Particle burst effects and screen shake feedback
- Sound effects generated via the Web Audio API (no audio files needed)
- High score tracking for the session
- Kid-friendly visuals: glossy bubbles, floating clouds, animated hearts

## Built With

- HTML5 Canvas
- Vanilla JavaScript
- Web Audio API
